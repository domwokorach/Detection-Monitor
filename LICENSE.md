## Decision required

The project owner must decide how the work is to be licensed. This has **not** been decided, and no licence has been applied automatically. Typical options, for the owner to consider (not a recommendation, and not legal advice):

| Option | Effect |
|---|---|
| Keep all rights reserved | Portfolio viewing only. No reuse |
| Permissive open source (for example MIT or Apache-2.0) | Others may reuse and modify with few conditions. Apache-2.0 adds an express patent grant |
| Copyleft open source (for example GPL-3.0 or AGPL-3.0) | Others may reuse, but derivative works must remain open. AGPL extends this to network use |
| Source-available or commercial licence | Custom terms, for example non-commercial use only or paid licences |

Before choosing, the owner should:

1. Confirm they own, or have the right to license, all original code, design, copy, screenshots and artwork ([COPYRIGHT.md](COPYRIGHT.md)).
2. Confirm that every third-party dependency and asset is compatible with the intended licence.
3. Resolve the unconfirmed provenance of the logo and shield artwork.
4. Take legal advice if the project will be commercialised.

When a decision is made: add the chosen licence text as `LICENSE` (or `LICENSE.md`), update the badge in `README.md`, add a `license` field to the package manifests, add file headers if the chosen licence requires them, and revise this page.
